# Ice Route Planner

Spoke/Circuit benzeri, kendi kullanımımız için geliştirilen Android rota ve teslimat uygulaması.

## İlk sürüm
- Google Maps SDK haritası
- GPS konumu
- Müşteri durakları
- Sıradaki müşteri
- Google Maps navigasyonuna geçiş
- Teslim edildi
- 10 dakika servis süresi göstergesi

## Google Maps API key
`MAPS_API_KEY` değişkenini Android build ortamında tanımlayın. Google Cloud'da Maps SDK for Android'i etkinleştirin.
